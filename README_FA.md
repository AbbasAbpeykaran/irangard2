# ایرانگرد — اطلس آفلاین ایران (نسخه توسعه راهنمای فارس)

## اجرا

1. Node.js و npm را نصب کنید.
2. در پوشه‌ی پروژه اجرا کنید:

```bash
npm ci
npx expo start
```

3. برای اجرای اندروید، از Expo Go یا شبیه‌ساز اندروید استفاده کنید.

## قابلیت‌های این نسخه

- هویت اطلس تعاملی ایران با نقشه‌ی رنگی و محلی
- داده‌ی مرز و نام ۳۱ استان در فایل محلی
- انتخاب استان با لمس نقشه یا فهرست استان‌ها
- جست‌وجوی نام فارسی/انگلیسی استان و شهرهای موجود در داده‌ها
- ذخیره‌ی بازدیدها روی دستگاه
- راهنمای فعلی فارس با ۴۲ مکان یکتا: ۳۵ مکان در شیراز و ۷ مقصد در سایر نقاط استان فارس
- دسته‌بندی جاذبه‌ها و ۷ خوراکی/سوغات محلی
- حذف مکان‌های دارای هویت یا وضعیت دسترسی نامطمئن از فهرست اصلی

## محدوده‌ی آفلاین

نقشه، داده‌ی استان‌ها، محتوای فعلی راهنمای شیراز و علامت‌های بازدید در دستگاه نگهداری می‌شوند. در این نسخه، راهنمای گردشگریِ فعلی فقط برای شیراز و مقصدهای منتخب استان فارس وجود دارد؛ استان‌های دیگر هنوز محتوای گردشگری کامل ندارند. مسیرهای پیشنهادی از این نسخه حذف شده‌اند.

## کنترل پیش از انتشار

روی سیستم توسعه‌دهنده اجرا کنید:

```bash
npm ci
npx tsc --noEmit
npx expo start --android
```

سپس برنامه را در حالت پرواز باز کنید و انتخاب استان‌ها، بازکردن راهنمای شیراز و ماندگاری وضعیت بازدید بعد از بستن و بازکردن برنامه را آزمایش کنید. در این تحویل، اجرای Expo/Android روی دستگاه واقعی تأیید نشده است.
